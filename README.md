# JARVIS · CODEXIA

Web app for the CODEXIA hackathon (Tecnológico de Monterrey, Campus Sonora Norte, 7 Nov 2026). High-school teams build their own AI assistant by scanning printed QR cards, boot it in front of everyone, and use it during the day for station hints, a mission log, scores and photos. Includes a pre-built JARVIS for the Ghost Network VR station.

- Static site (GitHub Pages), no build step. Claude API key lives in a Cloudflare Worker (`worker/`).
- Documentation is in Spanish: see [LEEME.md](LEEME.md) and `guia.html`.
